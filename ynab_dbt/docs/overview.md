# YNAB Personal Finance Analytics

This project transforms YNAB and FRED data into budgeting, spending,
net-worth, and inflation analysis models.

## Start Here

- Explore the **reporting** models for dashboard-ready views.
- Explore the **marts** models for analytical tables.
- Use the lineage graph to trace data back to YNAB or FRED.
- Review exposures for intended dashboard and analysis use cases.

## Data Flow

YNAB API and FRED API -> Snowflake raw data -> staging -> marts -> reporting
